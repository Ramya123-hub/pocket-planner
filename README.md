# 📒 Pocket Planner

Pocket Planner is a simple and user-friendly personal planning application designed to help users organize their daily tasks, manage schedules, and keep track of important activities in one place.

## ✨ Features

* 📝 Create and manage tasks
* 📅 Organize daily activities
* ⏰ Keep track of schedules and deadlines
* ✅ Mark tasks as completed
* 🔐 User authentication
* ☁️ Firebase integration
* 📱 Responsive and user-friendly interface
* 💾 Store and manage user data

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Firebase**

  * Firebase Authentication
  * Firebase services for data management

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ramya123-hub/pocket-planner.git
```

### 2. Open the project

```bash
cd pocket-planner
```

Open the project folder in **VS Code**.

### 3. Run the application

You can use the **Live Server** extension in VS Code or open the HTML file in your browser.

## 🔥 Firebase Setup

This project uses Firebase for authentication and/or data management.

To run your own Firebase configuration:

1. Create a Firebase project.
